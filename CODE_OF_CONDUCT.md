# Code of Conduct

We want `semcode-search` to be a welcoming, technical and constructive open-source project.

Participants are expected to:
- be respectful and professional
- discuss technical ideas without attacking people
- welcome useful questions and different approaches
- provide actionable feedback
- respect project and security boundaries

Unacceptable behavior includes harassment, threats, discrimination, personal attacks, deliberate disruption and publishing private information without permission.

Maintainers may moderate discussions, close conversations or remove contributions that violate this code.

Security reports should follow [SECURITY.md](SECURITY.md).

For conduct concerns, contact the project maintainer through the contact information associated with the GitHub repository.
