# 🔌 Plugins para semcode-search

Plugins y extensiones para integrar `semcode-search` con tus editores favoritos.

## 📦 Plugins Disponibles

| Editor | Carpeta | Estado |
|--------|---------|--------|
| **VSCode** | [`vscode/`](./vscode/) | ✅ Disponible |
| **Neovim** | [`neovim/`](./neovim/) | ✅ Disponible |
| **JetBrains** | - | 🚧 Próximamente |

## 🚀 Instalación Rápida

### VSCode
1. Copia `vscode/` a `%USERPROFILE%\.vscode\extensions\semcode-search-vscode`.
2. Reinicia VSCode.
3. Pulsa `Ctrl + Shift + F` para buscar.

### Neovim
1. Añade el plugin a tu `init.lua`.
2. Pulsa `<leader>ss` para buscar.

## 📖 Documentación

Cada plugin tiene su propio `README.md` con instrucciones detalladas.

## 🛠️ Contribuir

¿Quieres crear un plugin para otro editor? 
1. Crea una carpeta dentro de `plugins/` con el nombre del editor.
2. Añade el código del plugin.
3. Añade un `README.md` explicando cómo instalarlo.
4. Haz un Pull Request.
